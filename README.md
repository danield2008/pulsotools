# PulsoTools

Web responsive de herramientas rápidas y generadores creativos.

## Publicar con GitHub Pages
1. Abre Settings → Pages.
2. En Build and deployment selecciona Deploy from a branch.
3. Selecciona `main` y `/ (root)` y pulsa Save.
4. Espera a que termine el despliegue.

Incluye animaciones CSS, animaciones de entrada al desplazarse, efectos hover, filtros, búsqueda y seis herramientas interactivas. Los generadores son plantillas locales y no usan IA ni guardan datos.
